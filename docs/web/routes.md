# Website route inventory

All pages use the Clear sky shell and local content. Native account operations remain in the native apps; website forms accept inquiries and launch interest.

| Route                                    | Purpose                                                |
| ---------------------------------------- | ------------------------------------------------------ |
| `/`                                      | Exact Clear sky homepage                               |
| `/product/home`                          | Account overview with DOM phone illustration           |
| `/product/budget`                        | Budget narrative and illustration                      |
| `/product/activity`                      | Activity narrative and illustration                    |
| `/about`                                 | Purpose and principles                                 |
| `/blog`                                  | Journal index                                          |
| `/blog/understanding-recurring-spending` | Full recurring-spending article                        |
| `/blog/tracking-manual-expenses`         | Full manual-spending article                           |
| `/careers`                               | Working principles and careers inquiry                 |
| `/press`                                 | Product background, downloadable SVGs, press inquiry   |
| `/help`                                  | Searchable local help                                  |
| `/help/in-app-support`                   | In-app support guide and support inquiry               |
| `/status`                                | Verified dated design milestone and update information |
| `/privacy`                               | Privacy policy and privacy inquiry                     |
| `/terms`                                 | Terms                                                  |
| `/delete-data`                           | Deletion guidance and request form                     |
| `/licenses`                              | Font/software notices                                  |
| `/contact`                               | Categorized inquiry form                               |
| `/waitlist`                              | Standalone waitlist and platform selection             |
| `/privacy-policy`                        | HTTP 301 to `/privacy`                                 |
| `/terms-of-service`                      | HTTP 301 to `/terms`                                   |
| `/robots.txt`                            | Environment-sensitive crawler policy                   |
| `/sitemap.xml`                           | Canonical-origin sitemap; requires configured origin   |
| `/api/waitlist`                          | POST-only private signup persistence                   |
| `/api/contact`                           | POST-only private inquiry persistence                  |

Unknown routes return HTTP 404 with the branded recovery page. Subscriptions, Insights, Voice, Security, and final CTA preserve their homepage anchors. API responses never disclose membership or record contents.
