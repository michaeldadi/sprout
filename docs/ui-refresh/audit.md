## KEEP / REDESIGN / CONSOLIDATE

- **KEEP:** native SwiftUI and Compose, existing auth and verification paths, platform system controls, SwiftData/Room and sync/API boundaries, the intended green brand cue, existing deep-link URL support, and reusable loading/toast/social-login work where it proves functional. Preserve security and user data semantics.
- **REDESIGN:** the empty core task surfaces and post-auth shell, navigation hierarchy and labels, finance information order and state representation, ambiguous subscription language, settings discoverability/recovery, and motion/accessibility behavior. This is a substantial product UI redesign, not a new application.
- **CONSOLIDATE:** repeated iOS RGB/gradient/font/field code; Android dynamic-theme versus local green auth styling; repeated auth fields/buttons; Settings-only components that should become small reusable native patterns where genuinely repeated. Avoid moving data/service ownership into UI components.
